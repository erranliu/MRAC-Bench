# Spec 产品客户端适配层与CLI接入

任务 ID：71；任务名称：产品客户端适配层与CLI接入；目标：`CORE-IMPLEMENTATION-DECOUPLING`。配套 [Plan](core-decoupling-10-client.plan.md)。硬前置：#68 [重构后代码清理](core-decoupling-07-cleanup.spec.md)整体交付；一个实现 PR。

## 目标与范围

遵守[后续维护共同约束](core-maintenance-constraints.md)。为现有 CLI/TUI 能力建立唯一产品客户端适配层，集中配置/身份解析、开库/关闭、连接探测、Query/Command 和文件 control 请求/回执调用；交付产品纯 DTO 与小接口，接通现有 CLI 产品查询和变更消费者。TUI 的完整迁移由 #72 完成。

承接 #66 的显式应用构造及既有 query/projection，不增加 HTTP/SSE、后台调度或产品动作，也不改变 #45 的硬前置。CLI 的安装、版本、服务窗口承载等管理入口仍由原外层负责；产品查询/任务命令/反馈/服务控制使用本适配层，权限和资格仍由中心校验。

## 产品契约

| 能力 | 输入/结果 | 必须保留的语义 |
| --- | --- | --- |
| 项目与连接 | 公共项目引用、服务/进程实例身份、连接状态、诊断、能力和非秘密方案摘要 | 同仓不同配置的项目归属不能混淆；不暴露 Config、DB、可写 Runtime 或平台配置 |
| 查询 | 任务/DAG/执行/决策、规范会话/正文/raw/能力、命令及有界日志；稳定身份/版本/游标 | 同一快照、UTF-8/字节预算、raw 完整性和旧 Attempt 隔离沿现有 query；不复制投影或分页规则 |
| 命令 | 现有动作的类型化目标/载荷、版本、发起者和幂等键；提交和查询回执 | 区分未提交、已接受、已执行、拒绝、重放和待核实；不把 accepted 当完成 |
| 生命周期与离线 | 明确打开/关闭客户端资源、读取离线当前格式历史 | 关闭客户端不停止服务/worker；离线只读不得建库、迁移、调度或消费命令 |

1. 产品契约放在纯包，复用现有 contracts/execution/taskview 中的稳定纯 DTO；缺少的连接/项目/日志/控制纯值归唯一所有者，移走或删除旧定义。不能再通过中心别名获得公开类型，不能复制一套业务 Runtime。大小、游标、身份、错误/结果状态明确类型化，不以 string action + any 或无身份 map 暴露任意中心调用。
2. 默认客户端实现位于主包外，消费既有应用查询/命令及控制端口。数据库/配置/连接的具体构造由应用组装注入，客户端不反向依赖组装包或 SQL 实现；资源在一次读取/会话范围明确关闭。所有数据来源继续走 query/projection 和原 CommandService，不自行解释表、平台历史或实现配置封套。
3. CLI 产品入口解析参数和显示结果后调用本客户端；业务资格、Decision/当前代次、版本与身份校验仍在中心。保留现有命令输出与错误语义，若内部格式确需改变按共同约束明确拒绝旧开发格式。不存在 CLI 保留旧默认路径、TUI 再建一条同类 adapter 的长期双实现。
4. 原请求 ID 在首次变更发送前固定，超时/丢回执后查询原请求；同 ID 异内容拒绝，已经登记的未知外部结果仅对账。适配层不因错误重新启动服务、换实例、自动补交未知动作或绕过当前授权。
5. 不存在与查询不匹配的隐式变更：纯查询不准备工作区或调用变更能力，服务离线/库缺失/旧格式/身份冲突/未知记录各自报告。过程失败不能伪装为 command_not_found 或成功空页。
6. 本项把现有 console/source.go 中默认源的 I/O 逻辑接到新客户端唯一实现；为尚未迁移的 TUI 保留必要的薄映射接线，由 #72 当场删除。薄映射不得保留第二份查询、控制、资格或配置解释。本项至少接通 CLI 真实消费者，不能只声明未来接口。

## 并行与交接

可与 #69/#70 并行，不消费写端口或具体 Store。客户端使用的读取/命令工厂通过纯产品端口注入；#70 改变内部存储时只替换组装构造，客户端契约保持。公共 DTO 和 CLI 段由本项拥有，contracts 原共享字段不同时修改。

#72 获得 CLI 已消费的纯契约、唯一 adapter、明确资源生命周期及暂存薄映射删除清单。组装层可以依赖客户端实现和 TUI，二者不反向导入应用组装。
